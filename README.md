# Carlos Michael Marpaung - Portfolio Website

A modern, responsive portfolio website showcasing my experience as a Software Engineer specializing in Backend Development and Full-Stack Systems.

## ✨ Features

- 🌓 **Dark/Light Mode** - Seamless theme switching with default dark mode
- 📱 **Fully Responsive** - Optimized for mobile, tablet, and desktop
- ⚡ **Fast Performance** - Built with Vite for lightning-fast development and builds
- 🎨 **Modern UI/UX** - Clean, professional design with smooth animations
- 🔗 **Direct Links** - Quick access to CV, GitHub, LinkedIn, and email
- 📊 **Project Showcase** - Detailed project cards with tech stacks and GitHub links
- 🎓 **Experience Timeline** - Visual representation of work experience with company logos
- 📜 **Certifications** - View certificates with direct links

## 🛠️ Tech Stack

- **Frontend Framework:** React 19.2.4
- **Language:** TypeScript 5.8.2
- **Styling:** Tailwind CSS
- **Build Tool:** Vite 6.2.0
- **Deployment:** Vercel

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or yarn package manager

### Installation

1. Clone the repository
```bash
git clone https://github.com/carlosmarpaung08/carlos-marpaung-portfolio.git
cd carlos-marpaung-portfolio
```

2. Install dependencies
```bash
npm install
```

3. Start development server
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:3000`

## 📦 Build for Production
```bash
npm run build
```

The build output will be in the `dist/` directory.

## 🎨 Customization

### Update Personal Information

Edit `src/data.ts` to update:
- Personal information (name, email, links)
- Work experiences
- Projects with GitHub links
- Skills and tech stack
- Education background
- Certifications with certificate links

### Modify Styling

The project uses Tailwind CSS. Main colors and theme configuration are defined in `tailwind.config.js`:
- Primary: Navy Blue (#002B5B)
- Dark Mode: Slate colors
- Accents: Blue gradients
